# Project Summary
The project is an advanced QR Code Generator website that empowers users to create customizable QR codes from links. Users can personalize their QR codes with various design options, including frames, patterns, and corner styles, while also having the ability to apply individual colors and gradients to different components of the QR code. The application features a modern, user-friendly interface, enabling users to generate, customize, and download QR codes instantly.

# Project Module Description
- **AdvancedQRGenerator**: Main component for inputting URLs and generating advanced QR codes with extensive customization options, including color and gradient settings.
- **QRCodeDisplay**: Displays the generated QR code and provides download functionality.
- **AdvancedCustomizationPanel**: Allows users to customize QR code properties such as size, colors, frames, patterns, and corner styles, including gradient options.

# Technology Stack
- **React**: JavaScript library for building user interfaces.
- **TypeScript**: Superset of JavaScript for type safety.
- **Vite**: Build tool for faster development.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **QRCode Library**: For generating QR codes.
- **html2canvas**: For downloading QR codes as images.
- **qr-code-styling**: Library for enhanced QR code styling options.

# Usage
1. **Installation**: Run the following command to install dependencies:
   ```
   pnpm install
   ```
2. **Build**: To build the project for production, run:
   ```
   pnpm run build
   ```
3. **Lint**: To check code quality, execute:
   ```
   pnpm run lint
   ```
